## 一、内容安全审核的目的

本平台实施内容安全审核的主要目的包括：

（1）履行中华人民共和国法律法规、监管要求及相关政策要求；  
（2）防止本平台被用于制作、复制、发布、传播违法违规信息；  
（3）防止本平台被用于危害国家安全、公共安全、网络安全或社会公共利益；  
（4）防止本平台被用于侵犯他人知识产权、个人信息权益、隐私权、名誉权、商业秘密或其他合法权益；  
（5）防止本平台被用于网络攻击、恶意代码生成、诈骗、垃圾信息、批量滥用、绕过计费、绕过安全机制等行为；  
（6）保障用户账号安全、平台系统安全、服务稳定性及交易安全；  
（7）处理用户投诉、申诉、争议、安全事件和监管协查事项；  
（8）维护本平台及其他用户的合法权益。

## 四、内容安全审核的节点

本平台可能在以下节点进行内容安全审核：

### 4.1 请求转发前审核

在您通过网页聊天或 API 提交内容后，本平台会在将相关请求转发至境外服务器或第三方模型服务商前，对用户内容进行内容安全审核。

如用户内容被判定存在违法、违规、敏感、侵权、滥用或其他风险，本平台有权拒绝转发该次请求，并向您返回相应安全提示。

### 4.2 模型内容返回后审核

第三方模型服务商返回模型生成内容后，本平台可能对模型生成内容进行内容安全审核。

如模型生成内容被判定存在违法、违规、敏感或其他风险，本平台有权不向您返回该内容、部分返回、替换为安全提示，或采取其他必要措施。

### 4.3 事后风控和安全审核

对于异常账号、异常调用、批量请求、疑似滥用、投诉举报、监管要求、安全事件、申诉复核等情形，本平台可能进行事后风控和安全审核。

### 4.4 人工复核

对于机器审核判断存在风险、违法、敏感、疑似误判、用户申诉或需要进一步确认的内容，本平台可能交由人工进行必要复核。

## 五、内容安全审核的方式

本平台采用机器审核与人工复核相结合的方式进行内容安全审核。

### 5.1 机器审核

机器审核方式包括但不限于：

（1）关键词规则；  
（2）自研内容安全审核模型；  
（3）分类模型；  
（4）风险评分；  
（5）上下文分析；  
（6）异常请求识别；  
（7）接口滥用检测；  
（8）账号风控模型；  
（9）其他自动化安全检测技术。

### 5.2 人工复核

在以下情形下，本平台可能进行人工复核：

（1）机器审核判断内容存在风险、违法、敏感或需进一步确认；  
（2）用户对审核结果、违规记录、账号限制或封禁决定提出申诉；  
（3）内容涉及投诉、举报、争议、侵权、安全事件或监管协查；  
（4）本平台合理认为需要人工判断或复核的其他情形。

### 5.3 自动化审核的局限性

您理解并同意，自动化审核技术可能存在误判、漏判、延迟或无法准确理解上下文的情况。

本平台会持续优化审核规则和模型，但不保证审核结果在任何情况下均完全准确。若您认为审核结果有误，可以按照本告知书规定的申诉方式向本平台提出申诉。

## 九、违规等级与账号处置规则

### 9.1 一般违规

一般违规包括但不限于：

（1）提交或尝试生成低风险违法违规、侵权、骚扰、垃圾信息等内容；  
（2）多次提交可能违反本平台规则但尚未构成严重违规的内容；  
（3）轻微规避审核、轻微滥用接口或其他一般违反平台规则的行为；  
（4）本平台根据审核结果认定为一般违规的其他情形。

**用户在 180 天内累计触发 5 次经本平台确认的一般违规记录的，本平台有权封禁其账号。**

### 9.2 严重违规

严重违规包括但不限于：

（1）涉恐、极端主义、暴力犯罪相关违法内容；  
（2）法律法规禁止的政治类违法信息；  
（3）儿童色情、未成年人性剥削或其他严重侵害未成年人权益的内容；  
（4）攻击平台、攻击第三方系统、生成恶意代码、漏洞利用、网络入侵等危害网络安全的行为；  
（5）批量滥用、恶意刷量、绕过计费、绕过限流、非法转售或二次代理；  
（6）侵犯个人信息权益，包括违法收集、处理、传输、买卖、泄露个人信息；  
（7）恶意规避、绕过或破坏内容安全审核机制；  
（8）诈骗、赌博、黑灰产、洗钱、非法交易等违法活动；  
（9）本平台根据审核结果认定为严重违规的其他情形。

**用户在 180 天内累计触发 3 次经本平台确认的严重违规记录的，本平台有权封禁其账号。**

### 9.3 特别严重违规

对于情节特别严重、涉嫌违法犯罪、危害国家安全、严重危害公共安全、严重攻击平台系统、造成重大损失或重大合规风险的行为，本平台有权不受累计次数限制，立即采取暂停服务、封禁账号、拒绝重新注册、依法报告等措施。

### 9.4 申诉成功后的处理

用户申诉成功的，本平台将撤销或调整相应违规记录。相应违规次数将不再计入累计封禁次数。

## 十、违规内容与审核记录的保存

### 10.1 普通 API 请求

对于未触发内容安全风险的正常 API 请求，本平台原则上不长期保存完整用户输入内容和完整模型输出内容。

本平台会保存必要的 API 请求/响应元数据日志 30 天，包括但不限于用户 ID、IP 地址、请求时间、调用模型、token 数、消耗金额、请求状态、错误码或其他必要技术信息。

### 10.2 API 上下文内存缓存

为完成多轮对话、上下文处理、请求转发和结果返回，本平台可能在运行内存中临时保存 API 上下文内容。

**API 上下文内容的内存释放周期为 1800 秒。释放后，本平台不再保留该等普通 API 上下文内容，但触发内容安全风险、违规记录、争议处理或法律法规保存要求的内容除外。**

### 10.3 网页聊天记录

当您使用网页聊天服务时，本平台会在您的账号中保存网页聊天记录，以便您查看历史记录、继续会话和管理聊天内容。

您可以自行删除网页聊天记录。您删除网页聊天记录后，对于未触发内容安全风险、投诉争议或法律法规保存要求的普通聊天记录，我们将立即删除，不再保留该等普通聊天内容。

### 10.4 风险内容和违规内容

对于本平台审核认定存在风险的内容，我们可能保存相关内容及审核记录 180 天。

对于机器审核判断为违法、敏感或违规并被本平台拒绝的请求，我们可能将该次请求相关内容、上下文、模型返回内容、用户信息、请求时间、IP 地址、调用模型、处置结果等作为安全日志保存 180 天，并交由人工审核处理。

### 10.5 保存期限届满后的处理

保存期限届满后，本平台将删除或匿名化处理相关信息，但法律法规、监管要求、司法机关、行政机关、安全事件处理或争议处理要求继续保存的除外。

## 十一、人工复核与工作人员保密义务

### 11.1 人工复核范围

本平台仅在必要范围内进行人工复核。人工复核通常限于以下情形：

（1）机器审核命中风险；  
（2）用户提出申诉；  
（3）涉嫌严重违法违规；  
（4）存在安全事件、投诉、举报、争议；  
（5）监管、司法或行政机关依法要求；  
（6）本平台为保障服务安全和合法合规所必需的其他情形。

### 11.2 最小必要原则

本平台将按照最小必要原则限制人工复核范围，仅允许有必要接触相关内容的工作人员在完成其职责所需范围内访问相关信息。

### 11.3 保密与安全管理

本平台将对接触相关内容的工作人员进行权限管理、保密要求和安全培训，并采取访问控制、日志记录、权限审批等措施，防止未经授权的访问、使用、泄露或滥用。
