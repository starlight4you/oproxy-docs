# Affiliate Rebates

Invite new users and convert your rebate quota into account balance.

## Open the page

After signing in to Oproxy, open [Affiliate Rebates](https://oproxy.world/affiliate) from the sidebar.

![Affiliate page when invite access is not enabled](/images/oproxy-steps/referral-access.png)

*Figure: The page state before an invitation code is enabled. Live controls may differ after approval.*

## Invite access

### Invite access is not enabled

When no exclusive invite code is assigned, the page indicates that invitations are unavailable. Contact WeCom support to request invite access.

[Contact WeCom Support](https://work.weixin.qq.com/ca/cawcde03c0826cf9e7)

::: info After invite access is enabled
The page may show an invite code, invite link, rebate statistics, balance-transfer controls, and invitee records. Use the signed-in page for the current rate, quota, and transfer conditions.
:::
