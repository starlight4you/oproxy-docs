# Chat / Agents

This page is reserved for Oproxy's built-in **Chat / Agents** feature. Complete instructions will be added as the feature and interface become available.

![Oproxy chat and agent app center](/images/oproxy-steps/app-centre.png)

*Figure: The console entry for chat and agent applications. Follow console announcements for current availability.*

::: info Reserved help page
The live console determines whether sessions, agents, or temporary access keys can be created. During maintenance, wait for an announcement instead of repeatedly creating API keys.
:::

## Open the feature

Sign in to Oproxy and select [Chat / Agent Applications](https://oproxy.world/app-centre) from the sidebar.

## Planned documentation

- Open the built-in chat application;
- Create a conversation and select a model;
- Create, renew, and disable temporary access keys;
- Create and manage agents;
- Manage history, attachments, and tool permissions;
- Resolve common errors and maintenance states.

## Before use

- Use an API key with a spending limit and expiration when appropriate.
- Never paste a complete API key into a conversation, screenshot, or support ticket.
- Read the privacy, cross-border transfer, and content-safety notices before processing sensitive content.
- If the page does not open, check console announcements and Model Monitoring before contacting support.
