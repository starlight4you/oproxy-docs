# RikkaHub and Mobile Chat Clients

Add an OpenAI-compatible provider with `https://api.oproxy.world/v1`, a mobile-specific Oproxy key, and an exact model ID.

![Oproxy API endpoints](/images/oproxy-steps/api-endpoints.png)

*Figure: Mobile OpenAI-compatible clients normally use the Oproxy gateway plus `/v1`.*

Protect the device with a lock and biometrics, avoid clipboard synchronization and key screenshots, and disable the key immediately if the device is lost. Set a spending limit and expiration for mobile keys.

Test plain text first, then enable images, reasoning, or tools one at a time. If the built-in chat link displays a Cloudflare Tunnel error, the chat application is usually under maintenance; use another client and check console announcements.

![Oproxy chat and agent app center](/images/oproxy-steps/app-centre.png)

*Figure: The console app center provides chat and agent entry points; current availability follows the live notice.*
