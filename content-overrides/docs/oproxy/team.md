# 企业、实验室与组织

Oproxy 的企业方案面向需要更高稳定性、团队治理和数据保护的组织。

## 企业页面提供什么

[面向企业](https://oproxy.world/business) 页面列出：

- 7×18 支持；
- 自定义管理入口；
- 优化 API；
- 专属额度与路由；
- 团队成本治理；
- 数据安全与隔离。

## 联系表单

必填字段为公司/组织、联系人、邮箱和使用场景；电话/微信、预计用量和补充说明为可选。提交会把信息发送给平台，应由有权代表填写真实且必要的内容。

## 数据保护

公开说明称普通服务不会把用户内容用于 Oproxy 自身模型训练，也不会出售用户数据；但第三方模型服务商可能按其政策处理数据。对不训练、专属上游、数据隔离、科研或商业秘密有要求时，应在使用前申请企业通道并通过书面协议明确边界。

## 团队使用建议

- 不共享个人账户或 API Key；按系统和环境分别创建 Key。
- 对生产 Key 设置 IP、额度、速率和有效期限制。
- 由管理员定期查看使用记录、订单、订阅和模型监控。
- 把敏感数据分类、最小化并在提交模型前脱敏。
- 发生异常时先禁用相关 Key，保留请求 ID 和时间，再提交工单。

## 支持渠道

企业页面提供微信客服；也可通过 `support@oproxy.world` 联系。涉及合同、开票、退款或数据保护要求时，说明组织、场景、预计用量和所需保障。
