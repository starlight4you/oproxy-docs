# 校园大使计划

## 操作教程

::: warning 开始前需要先申请
校园大使功能不是注册后自动开通的。请先登录 Oproxy 控制台，进入[邀请返利](https://oproxy.world/affiliate)页面，按页面提示提交校园大使申请并等待人工审核。只有页面明确显示“你已成为……校园大使”后，才能继续使用校园大使邀请和返现功能；提交申请不代表自动通过。
:::

### 第一步：进入邀请返利页面

登录 Oproxy 控制台，在左侧导航栏点击 **邀请返利**。如果账号尚未开通校园大使资格，请先在这个页面完成申请；审核通过后再次进入该页面即可看到校园大使状态和专属返利信息。

![在控制台左侧导航栏进入邀请返利页面](/images/campus-ambassador/affiliate-entry.png)

### 第二步：确认校园大使状态

审核通过后，页面会显示校园大使提示、返利比例以及邀请数据概览。请先确认页面显示的学校域名和校园大使身份正确，再开始分享邀请信息。

页面顶部的数据卡片分别显示：

- **我的返利比例**：同校受邀用户完成有效充值后适用的校园返现比例。
- **邀请人数**：已经通过你的邀请码或邀请链接建立邀请关系的用户数量。
- **可转返利额度**：当前可以转入账户余额的返利。
- **历史返利额度**：账号累计获得的返利记录。

![校园大使返利比例和邀请数据概览](/images/campus-ambassador/rebate-overview.png)

::: info 页面数据以账号实际显示为准
截图仅用于说明字段位置。你的邀请人数和返利额度会根据账号实际情况变化；活动比例、资格和奖励规则以当前页面及下方活动说明为准。
:::

### 第三步：复制并分享邀请信息

在 **邀请返利** 卡片中找到 **我的邀请码** 和 **邀请链接**：

1. 点击 **复制邀请码**，可以把邀请码单独发送给新用户。
2. 点击 **复制链接**，可以直接分享带有邀请码的注册链接。
3. 提醒对方使用该邀请信息完成新账号注册，并确认邀请关系已经正确建立。

只有与校园大使属于同一学校邮箱域名、且满足活动条件的受邀新用户，才可获得校园初始额度。

### 第四步：查看邀请结果并转入余额

页面下方的 **已邀请用户** 区域用于查看邀请记录。受邀用户完成符合规则的充值后，返现会进入 **可转返利额度**；有可用额度时，点击 **转入余额** 即可将其转入 Oproxy 账户余额。

如果当前没有可转入额度，按钮会处于不可用状态。转入前建议先核对可转额度和邀请记录；已经转入的金额可通过历史返利额度和账户相关记录继续核对。

![返利额度转余额和已邀请用户区域](/images/campus-ambassador/rebate-transfer.png)

### 第五步：查看规则或联系支持

点击页面中的 **[查看活动说明与免责声明](https://oproxy.world/campus-ambassador-terms)** 可以查看完整规则。如果申请状态、邀请关系、同校身份或返利金额与预期不符，请保留必要的页面信息，并通过平台客服渠道咨询。

本说明用于帮助申请人与被邀请用户理解校园大使计划的参与条件、奖励规则、审核要求和活动边界。申请或继续参与本活动，即表示你已阅读并理解以下内容。

## 校园大使计划规则

## 一、适用对象与申请条件

- 校园大使计划面向平台用户开放申请。
- 用户需要在邀请返利页面主动提交申请，提交申请并不代表自动通过。
- 平台会根据账号状态、邮箱域名、历史使用情况和风控记录进行人工审核。
- 校园大使资格与审核通过时识别到的账号邮箱域名绑定；邮箱信息失效、变更或异常时，平台可以重新审核或暂停资格。

## 二、邀请关系与初始额度

- 校园大使的邀请码仍可作为普通邀请码使用，非教育邮箱用户也可以通过该邀请码注册并绑定邀请关系。
- 只有与校园大使属于同一邮箱域名的受邀新用户，才可获得 10 元初始额度。
- 同一受邀用户的校园初始额度只发放一次，不会因为重复绑定、重新申请或状态刷新而重复发放。
- 如果邀请关系、邮箱域名或账号状态不满足条件，系统不会发放校园初始额度。

## 三、校园大使返现规则

- 同域名受邀用户完成有效充值订单后，校园大使可获得该充值金额 12% 的返现。
- 校园大使返现记入邀请返利额度，可按邀请返利页面展示的规则转入账户余额。
- 校园大使返现与普通邀请返利不叠加；同一笔符合校园条件的充值优先按校园大使规则计算。
- 兑换码、管理员手动调整、返利转余额、API 消费扣费以及非充值订单产生的余额变化，不作为校园大使 12% 返现的计算基础。
- 如订单退款、撤销、支付异常或被认定存在风险，平台可以不发放、延迟发放、冻结或追回相关奖励。

## 四、层级与身份变化

- 校园大使计划不包含多级返现。A 邀请 B、B 再邀请 C 时，A 只根据 B 的合规充值获得返现，B 只根据 C 的合规充值获得返现。
- B 从 C 的充值中获得的返现不会被视为 B 的消费、充值或订单金额，也不会继续给 A 产生返现。
- 如果受邀用户之后也成为校园大使，不会改变其与原邀请人的既有邀请关系；原邀请人是否获得校园返现，仍以同域名、有效充值订单等条件为准。

## 五、合规使用要求

- 校园大使应基于真实、自愿、合规的方式进行推荐，不得发布虚假承诺、误导性价格、夸大宣传或冒充平台官方身份。
- 禁止自邀、批量注册、买卖或借用教育邮箱、伪造学校身份、诱导退款、刷单、套利、垃圾信息推广等行为。
- 平台发现异常行为时，可以拒绝申请、取消校园大使资格、冻结或扣回奖励，并按平台用户协议处理相关账号。

## 六、活动性质与规则调整

- 校园大使不是平台员工、代理商或授权代表，不代表平台对外作出承诺或承担代理职责。
- 活动奖励、比例、资格范围、审核标准和发放节奏可能根据运营情况、风控要求或合规要求调整。
- 平台会尽量通过页面、公告或站内通知同步重要变更；具体执行以系统记录和平台最终审核结果为准。

## 七、数据使用与联系渠道

- 为判断资格和计算奖励，平台会处理必要的账号信息、邮箱域名、邀请关系、充值订单和返利流水。
- 相关数据仅用于账号服务、活动审核、奖励发放、风控和客服核验等必要场景。
- 如对申请、审核结果或奖励明细有疑问，可通过平台客服渠道联系处理。

本说明是校园大使活动规则说明，不替代平台用户协议、隐私政策或其他已经生效的服务条款。若活动说明与平台通用规则存在冲突，以更严格、更适合风控与合规要求的规则为准。
