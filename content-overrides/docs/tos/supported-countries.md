# 注册资格、学校与支持

## 支持的注册方式

平台当前主要面向：

- 持有效邀请码并完成必要核验的用户；
- 受支持学校/组织的教育邮箱用户；
- 经审核或签约的企业、实验室和研发团队。

平台不向 18 周岁以下未成年人提供服务。

## 查询学校

[支持页](https://oproxy.world/support) 提供学校/组织名称搜索，以及国家、省份和城市筛选。选择中国后可继续选择省份和城市；列表显示学校名称和邮箱域名。

学校总数与名单会变化，不在本地文档复制完整列表。注册前直接搜索学校和教育邮箱域名。

## 不在列表怎么办

如果学校未收录、教育邮箱无法识别，或使用非教育邮箱：

1. 截取学校名称和邮箱域名，不要截取密码或验证码。
2. 联系管理员申请人工审核或账号创建。
3. 企业/实验室使用企业方案表单说明组织与场景。

## 支持渠道

- 邮箱：`support@oproxy.world`，支持页说明通常在 96 小时内响应。
- 微信客服：支持页与企业页提供企业微信入口。
- 登录后工单：用于问题跟踪和进度查看。

## 地区与跨境提示

平台服务涉及跨境模型调用。使用前应确认你所在地区、组织政策和数据类型允许相应处理；如不同意必要的跨境传输，网页聊天和 API 代理等核心功能可能无法使用。
