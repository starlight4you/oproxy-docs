# 常见问题

## 为什么登录或注册输入框是禁用的？

平台会先显示最新条款。阅读用户协议、隐私政策、个人信息跨境传输说明和内容安全规则后，由你本人点击 **同意并继续**，输入框才会启用。

## 哪些人可以注册？

平台当前采用受限注册：有效邀请码、受支持的教育邮箱，或经审核的企业、实验室和组织用户。可在 [支持页](https://oproxy.world/support) 搜索学校和邮箱域名；普通教育邮箱也可能需要人工审核。

## API Key 应该选哪个分组？

分组决定可用模型和计费渠道。创建密钥时根据目标模型选择 **按量计费**、**OpenAI-按量计费**、**Claude**、**Gemini** 或 **DeepSeek**。最终列表以你的账户页面为准。

## 默认端点和国内优化端点有什么区别？

- 默认：`https://api.oproxy.world`
- 国内优化：`https://open.oproxy.world`

先使用默认端点；网络条件需要时再测试国内优化端点。OpenAI 兼容客户端通常会在 Base URL 后使用 `/v1`，Codex Responses 与 Claude Code 的配置按对应指南填写。

## 为什么模型请求失败？

依次检查：Key 是否完整且活跃、分组是否支持该模型、Base URL 是否正确、余额或订阅额度是否足够、Key 是否受额度/有效期/IP/速率限制，以及 [模型监控](https://oproxy.world/monitor) 是否显示异常。具体处理参见 [错误码与处理](/docs/tokenflux/error-codes.html)。

## 429 和 503 有什么区别？

`429` 通常表示 RPM、TPM、并发、套餐额度或 Key 速率限制不足；先降低并发，持续不足时购买增强包或升级套餐。`503` 通常表示上游模型或渠道暂时不可用；先查看模型监控，等待后重试或切换模型。

## “打开聊天”为什么显示 Cloudflare Tunnel 错误？

这通常表示聊天应用正在维护。先查看控制台公告和模型监控；仍未恢复时联系 `support@oproxy.world` 或微信客服。

## 订阅和余额如何计费？

订阅提供按日、周、月限制的折扣额度；余额用于按量计费。控制台同时显示实际费用与标准费用。Token、缓存、图片、RPM 和并发的区别参见 [计费、充值与订阅](/docs/tokenflux/billing.html)。

## 能否退款？

用户协议说明：未使用的实际充值余额可申请退款，但需核验；已消费部分、赠送余额、优惠和部分订阅权益通常不退。提交前先阅读最新协议并联系支持。

## Oproxy 会长期保存 API 内容吗？

普通 API 请求的完整输入/输出原则上不长期保存；必要元数据日志保存 30 天，API 上下文内存通常在 1800 秒后释放。网页聊天记录保存在账号中直到删除。风险或违规内容与审核记录可能保存 180 天。

## 如何导出或查看调用明细？

在 **使用记录** 中选择 Key 和时间范围，可查看模型、端点、请求类型、Token、费用、首 Token、耗时和 User-Agent，并可导出 CSV。

## 如何联系客服？

邮箱为 `support@oproxy.world`，支持页说明通常在 96 小时内响应；工单可在登录后的控制台提交。
