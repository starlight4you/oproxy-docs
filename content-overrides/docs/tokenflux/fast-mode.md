# 仪表盘、监控与使用记录

控制台把账户概览、调用明细和平台可用性分成三个页面。

## 仪表盘

[仪表盘](https://oproxy.world/dashboard) 展示：

- 余额、API Key 数量、今日/累计请求与消费；
- 今日与累计 Token、输入/输出拆分；
- RPM、TPM、平均响应时间；
- 按 OpenAI、Aggregate、Claude 等平台拆分；
- 模型分布、Token 趋势、最近使用和快捷操作。

时间范围、粒度和刷新按钮只影响展示，不改变账户配置。

## 使用记录

[使用记录](https://oproxy.world/usage) 可按 API Key 与时间范围筛选。预设包括今天、昨天、近 24 小时、7/14/30 天、本月、上月，也可填写起止日期。

列表字段包括模型、推理强度、端点、流式/同步、计费模式、Token、费用、首 Token、总耗时、时间和 User-Agent。页面还支持：

- 刷新与重置筛选；
- 按模型和时间排序；
- 分页；
- 导出 CSV。

![使用记录页面的 API Key 和日期筛选栏](/images/oproxy-steps/usage-filters.png)

*图：先选择 API Key 和时间范围，再刷新、重置或导出当前筛选结果。*

::: warning 隐私
导出的 CSV 可能包含 Key 名称、调用时间和 User-Agent。只存放在受信任位置，不要公开上传。
:::

## 模型监控

[模型监控](https://oproxy.world/monitor) 提供 7、15、30 天视图，展示：

![模型监控页面，显示状态、延迟和可用性](/images/oproxy-steps/model-monitor.png)

*图：模型监控集中展示渠道状态、对话延迟、PING 和历史可用性。*

- 当前状态：正常、降级、错误或失败；
- 对话延迟与端点 PING；
- 时间范围内可用性；
- 最近探测历史；
- 手动刷新和倒计时自动刷新。

监控是平台探测结果，不保证某个账户、地区或模型分组一定相同。排错时应同时检查本地网络、端点、Key 限制和余额。
