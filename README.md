# Oproxy Docs 本地副本

这是 Oproxy 的本地帮助文档站，包含中文、英文文档、全文搜索、深色模式与移动端导航。

## 本地打开

macOS 可以双击 `start-local.command`。浏览器会在站点准备完成后自动打开。

也可以在此目录运行：

```bash
npm run dev
```

然后访问 `http://localhost:3000/`。

## 重建文档索引

需要重新同步线上文档时运行：

```bash
npm run sync:docs
```

该命令会从 `content-overrides` 同步本地 Markdown，并重建搜索索引与 Markdown Sitemap，不会连接或覆盖线上 Oproxy 数据。

## 包含能力

- 中文与英文文档导航
- Markdown、表格、代码块、Tabs 和提示框
- 本地全文搜索与 `Command/Ctrl + K` 快捷键
- 深色模式与移动端导航
- 原始 `.md` 文件
- 上一页、下一页与页内目录

## 内容边界

- 价格、模型可用性、公告和学校名单会随线上平台变化，文档以操作路径为主，并提示到对应页面查看实时值。
- 文档不保存真实 API Key、账户余额、邮箱、订单号或使用记录。
- 充值、创建密钥、提交工单、兑换码、账号安全等操作均只说明流程，不会在本地站触发线上操作。
