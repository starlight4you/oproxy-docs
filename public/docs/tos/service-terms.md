## 第一条 定义与解释

1.1 **本平台 / Oproxy**：指由本工作室运营并享有合法权益的 Oproxy 技术服务平台，包括但不限于域名为 **oproxy.world** 的网站、网页聊天服务、应用程序编程接口（API）、密钥管理系统、计费系统及本工作室后续开发或提供的其他技术产品和服务形态。

1.2 **服务**：指本工作室通过本平台向用户提供的网络通信技术接入、API 请求代理转发、网页聊天、模型调用中转、账户充值计费、内容安全审核、日志管理及相关技术服务。

1.3 **第三方模型服务商**：指与本平台无关联关系的第三方大型语言模型、生成式人工智能模型、API 服务、云服务、算力服务或其他相关服务的提供者。用户通过本平台访问或调用的模型能力，可能由第三方模型服务商独立提供。

1.4 **用户内容**：指用户在使用本平台服务过程中输入、提交、上传、发送或通过 API 请求传输的任何内容，包括但不限于文本、提示词、上下文、指令、代码、文档、图片链接、结构化数据及其他信息。

1.5 **模型生成内容**：指第三方模型服务商根据用户内容生成并通过本平台返回给用户的文本、代码、结构化数据或其他形式的信息。

1.6 **API 密钥**：指用户在本平台创建并用于访问本平台 API 服务的身份认证凭据，包括但不限于 API Key、访问令牌或其他鉴权信息。

1.7 **账户余额**：指用户通过充值、补偿、赠送或其他方式取得并显示于本平台账户中的可用于支付本平台服务费用的额度。其中，实际充值余额与赠送额度、补偿额度、优惠额度等可能适用不同使用和退款规则。

1.8 **违规内容**：指本平台依据法律法规、本协议、本平台内容安全规则或自动化/人工审核结果，认定可能违反法律法规、公序良俗、本协议或第三方服务商使用政策的内容。

1.9 **不可抗力**：指本协议双方不能预见、不能避免并不能克服的客观情况，包括但不限于自然灾害、战争、罢工、暴乱、法律法规或政策变化、政府行为、司法或行政机关命令、电信网络中断、互联网骨干线路故障、黑客攻击、计算机病毒、第三方服务中断、云服务故障及其他非因本工作室过错导致服务无法正常提供的情形。

## 第二条 服务内容与服务性质

### 2.1 服务内容

本平台目前向用户提供的服务包括：

（1）网页聊天服务：用户可通过本平台网页界面输入内容，并接收第三方模型服务商返回的模型生成内容；

（2）API 代理服务：用户可在本平台注册、充值、创建 API 密钥，并通过该密钥向本平台发送 API 请求。本平台在进行必要的安全审核、鉴权、计费和转发处理后，将请求转发至第三方模型服务商，并将第三方模型服务商返回的结果返回给用户；

（3）账户与计费服务：本平台向用户提供账户注册、登录、充值、余额管理、用量统计、账单展示、发票申请等功能；

（4）内容安全审核服务：本平台依据中国法律法规、本协议及平台安全规则，对用户内容和模型生成内容进行自动化审核，并在必要情况下进行人工复核；

（5）其他由本平台不时提供的相关技术服务。

### 2.2 服务性质说明

**用户理解并确认，本平台自身不训练、开发或运营通用生成式人工智能基础模型。用户通过本平台调用的模型能力主要由第三方模型服务商提供。本平台主要提供网页交互、API 接入、请求代理、传输转发、内容安全审核、账户计费及相关技术服务。**

但用户同时理解并确认：本平台作为向用户提供模型调用接入、网页聊天及 API 代理服务的平台，可能依法就网络安全、数据安全、个人信息保护、内容安全、日志留存、用户管理及监管配合等事项承担相应义务。

### 2.3 第三方模型服务商

用户理解并同意：

（1）第三方模型服务商独立提供模型能力，其模型效果、服务稳定性、输出内容质量、可用性、计费规则、数据处理规则及服务政策可能随时变化；

（2）本平台不保证第三方模型服务商的服务持续可用、无错误、无中断或始终符合用户特定需求；

（3）用户使用本平台服务时，应同时遵守相关第三方模型服务商的服务条款、使用政策、隐私政策及适用法律法规；

（4）因第三方模型服务商服务中断、变更、限流、封禁、政策调整、模型输出错误或数据处理规则变化而造成的影响，本平台将在合理范围内协助用户处理，但不对第三方模型服务商的行为或不行为承担超出法律规定或本协议约定的责任。

## 第六条 内容安全审核与处置

### 6.1 审核机制

为履行法律法规要求、维护网络空间安全、保护用户和公众合法权益，本平台会对用户内容及模型生成内容进行内容安全审核。

审核对象包括：

（1）用户在网页聊天中输入的内容；

（2）用户通过 API 提交的请求内容；

（3）第三方模型服务商返回的模型生成内容；

（4）本平台认为有必要审核的上下文、会话内容、请求参数、输出结果及相关日志。

### 6.2 审核方式

本平台采用机器审核与人工复核相结合的方式进行内容安全审核。机器审核方式包括但不限于关键词规则、自研审核模型、分类模型、风险评分、上下文分析及其他自动化技术手段。

在一般情况下，本平台会在用户请求转发给第三方模型服务商前，对用户内容进行自动化审核；在第三方模型服务商返回内容后，本平台也会对模型生成内容进行自动化审核。

对于机器审核判断存在风险、违法、敏感或需要进一步确认的内容，本平台有权交由人工进行必要复核。

### 6.3 审核处置

如本平台审核发现用户内容或模型生成内容可能违反法律法规、本协议或平台规则，本平台有权采取以下一种或多种措施：

（1）拒绝转发本次请求；

（2）中止或终止本次模型调用；

（3）不返回、部分返回或替换返回模型生成内容；

（4）向用户提示相关内容违反法律法规或本协议；

（5）记录违规情况；

（6）限制账号功能、降低额度、限流、暂停服务；

（7）封禁账号；

（8）依法向监管机关、司法机关或其他有权机关报告或提供相关信息；
