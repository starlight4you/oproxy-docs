**本说明是《Oproxy 用户服务协议》及《Oproxy 隐私政策》的组成部分，与该等协议和政策具有同等法律效力。本说明未定义的术语，适用《Oproxy 用户服务协议》及《Oproxy 隐私政策》中的定义。**

**请您在使用本平台服务前，审慎阅读并充分理解本说明全部内容。您点击“同意”、完成注册、登录、充值、创建密钥、使用网页聊天或 API 服务，或以任何其他方式继续使用本平台服务，即表示您已充分知悉并同意本说明所述跨境传输事项。如您不同意本说明的任何内容，请立即停止使用本平台服务。**

## 一、跨境传输的概述

### 1.1 跨境传输的必要性

本平台的核心服务包括网页聊天和 API 代理。用户通过本平台提交请求后，本平台会在完成必要的身份鉴权、计费、内容安全审核和技术处理后，将相关请求转发至境外服务器及第三方模型服务商，并将第三方模型服务商返回的模型生成内容返回给用户。

因此，为实现您主动请求的模型调用、网页聊天和 API 代理服务，部分数据跨境传输属于提供本平台核心服务所必需的技术环节。

**如您不同意必要的跨境传输，我们可能无法继续向您提供网页聊天、API 代理、第三方模型调用等核心服务。**

### 1.2 跨境传输路径

本平台目前通常的数据传输路径为：

> **中国大陆服务器 → 境外服务器 → 第三方模型服务商**

本平台中国大陆服务器主要使用中国大陆云服务资源，并已依法办理相关备案手续。境外服务器和第三方模型服务商可能位于中华人民共和国境外。

### 1.3 跨境传输的主要场景

您的个人信息或可能包含个人信息的数据，可能在以下场景中发生跨境传输：

（1）您使用网页聊天功能，向第三方模型服务商发起模型调用请求；  
（2）您通过 API 向本平台提交请求，由本平台代理转发至第三方模型服务商；  
（3）第三方模型服务商向本平台返回模型生成内容；  
（4）为完成请求转发、错误排查、结果返回、模型调用、上下文处理所必需的技术处理；  
（5）您选择或申请使用特定境外模型、境外上游服务或专门数据保护通道。

## 二、个人信息出境规模控制与合规路径说明

### 2.1 出境规模控制

本平台目前采取限制注册、邀请码、教育邮箱白名单、机构客户单独审核等方式控制用户范围和服务规模。

**我们将严格控制平台用户规模及个人信息出境规模，原则上保持平台个人信息出境规模低于适用法律法规规定的相关数量门槛。**

### 2.2 备案或合规程序安排

根据适用的个人信息出境相关法律法规，如本平台在一定期间内向境外提供个人信息的规模、类型、敏感程度等符合相关豁免条件，我们将在符合法律法规要求的前提下，依法适用相应豁免安排。

**如本平台未来不再符合相关豁免条件，或因法律法规、监管政策、业务规模、数据类型、用户数量、敏感个人信息处理情况等变化而需要履行个人信息出境安全评估、个人信息出境标准合同备案、个人信息保护认证或其他合规程序的，我们将依法履行相应程序，并在必要时更新本说明或另行告知用户。**

### 2.3 敏感个人信息限制

本平台不主动要求您在用户内容中提交敏感个人信息。除非服务所必需、法律法规允许且您已依法取得必要授权或同意，否则请勿通过本平台输入、上传或传输敏感个人信息、他人个人信息、商业秘密、保密信息、国家秘密或其他受保护信息。

如您违反前述要求，自行在用户内容中包含个人信息、敏感个人信息或他人受保护信息，您应确保具备合法处理依据，并自行承担由此产生的相应责任。

## 四、跨境传输的信息类型

### 4.1 可能传输至境外的信息

为实现网页聊天、API 代理、模型调用及结果返回，我们可能向境外传输以下信息：

（1）您输入的提示词、文本、指令、代码、问题或其他用户内容；  
（2）为完成多轮对话或模型调用所必需的上下文内容；  
（3）请求参数，例如模型名称、温度参数、上下文长度、输出长度、接口参数等；  
（4）所调用模型信息；  
（5）第三方模型服务商返回的模型生成内容；  
（6）为完成请求转发、错误排查、结果返回所必需的技术信息；  
（7）会话标识、请求时间等必要技术元数据。

### 4.2 原则上不因跨境传输目的主动传输的信息

除非为实现特定服务、用户另行授权、法律法规允许或另有必要，我们原则上不会因模型调用目的主动向境外传输以下账户和财务信息：

（1）手机号；  
（2）教育邮箱；  
（3）邀请码信息；  
（4）充值记录；  
（5）余额信息；  
（6）发票信息；  
（7）退款信息；  
（8）完整账号资料。

但请您理解，在网络通信、请求转发、安全防护、故障排查等技术过程中，部分必要技术信息可能随请求一并传输或被境外服务器处理。

### 4.3 用户内容中包含个人信息的风险提示

**您通过本平台提交的用户内容可能包含个人信息。例如，您在提示词、文档、代码注释、上下文或聊天内容中输入姓名、联系方式、身份信息、个人经历、简历、病历、财务信息、账号信息、客户信息或其他可识别个人的信息。**

您应谨慎决定是否在用户内容中包含个人信息。若您输入他人个人信息，应确保您已依法取得该个人信息主体的授权同意或具备其他合法处理依据，并已履行法律法规要求的告知义务。

## 五、跨境传输的目的和处理方式

### 5.1 跨境传输目的

我们进行跨境传输的主要目的包括：

（1）向第三方模型服务商发送您主动提交的模型调用请求；  
（2）接收第三方模型服务商返回的模型生成内容；  
（3）实现网页聊天、API 代理、上下文处理、模型调用和结果返回；  
（4）进行必要的请求转发、网络通信、错误排查和服务稳定性保障；  
（5）根据用户选择或另行协议，为实验室、企业、研发团队等客户提供专属上游、企业级服务或数据保护通道；  
（6）履行法律法规允许或要求的其他必要处理目的。

### 5.2 境外处理方式

境外接收方可能对相关信息进行以下处理：

（1）接收请求；  
（2）临时缓存或排队处理；  
（3）模型推理、文本生成或其他模型计算；  
（4）返回模型生成内容；  
（5）必要的错误排查、安全防护、日志记录或服务稳定性处理；  
（6）依据其自身服务条款、隐私政策或数据处理规则进行的其他处理。

### 5.3 第三方模型服务商的数据处理差异

不同第三方模型服务商的数据处理规则可能不同。部分第三方模型服务商可能根据其自身服务条款、隐私政策、账户类型、API 类型、产品设置或用户选择，对用户内容和模型生成内容进行存储、分析、服务改进或模型训练。

**本平台不会将您的用户内容用于本工作室自身模型训练，也不会出售您的用户数据。但第三方模型服务商是否保存、分析或使用相关数据进行服务改进或模型训练，取决于其自身政策、接入方式、账户类型和服务设置。**

如您对数据不被第三方模型服务商用于训练、保留或分析有特殊要求，应在使用相关服务前联系本平台客服或销售，申请开启专门的数据保护通道或签署另行服务协议。

## 六、本平台对跨境传输数据的保存规则

### 6.1 API 正常请求

对于未触发内容安全风险的正常 API 请求，本平台原则上不长期保存完整用户输入内容和完整模型输出内容。

为完成计费、账单、故障排查、安全审计和风控需要，本平台会保存必要的 API 请求/响应元数据日志 30 天，包括但不限于：

（1）用户 ID；  
（2）IP 地址；  
（3）请求时间；  
（4）调用模型；  
（5）token 数；  
（6）消耗金额；  
（7）请求状态、错误码或其他必要技术信息。

### 6.2 API 上下文内存缓存

为完成多轮对话、上下文处理、请求转发和结果返回，本平台可能在运行内存中临时保存 API 上下文内容。

**API 上下文内容的内存释放周期为 1800 秒。释放后，本平台不再保留该等普通 API 上下文内容，但触发内容安全风险、违规记录、争议处理或法律法规保存要求的内容除外。**

### 6.3 网页聊天记录

当您使用网页聊天服务时，本平台会在您的账号中保存网页聊天记录，以便您查看历史记录、继续会话和管理聊天内容。

您可以自行删除网页聊天记录。您删除网页聊天记录后，对于未触发内容安全风险、投诉争议或法律法规保存要求的普通聊天记录，我们将立即删除，不再保留该等普通聊天内容。

### 6.4 风险内容和违规内容

对于本平台审核认定存在风险的内容，我们可能保存相关内容及审核记录 180 天。

对于机器审核判断为违法、敏感或违规并被本平台拒绝的请求，我们可能将该次请求相关内容、上下文、模型返回内容、用户信息、请求时间、IP 地址、调用模型、处置结果等作为安全日志保存 180 天，并交由人工审核处理。

保存期限届满后，我们将删除或匿名化处理相关信息，但法律法规、监管要求、司法机关、行政机关或争议处理要求继续保存的除外。

## 七、内容安全审核与跨境传输的关系

### 7.1 出境前审核

在用户请求被转发至境外服务器或第三方模型服务商之前，本平台会依据中国法律法规、本平台规则及内容安全要求，对用户内容进行内容安全审核。

审核方式包括但不限于：

（1）关键词规则；  
（2）自研审核模型；  
（3）分类模型；  
（4）风险评分；  
（5）上下文分析；  
（6）其他自动化安全检测技术。

### 7.2 回传内容审核

第三方模型服务商返回模型生成内容后，本平台也会对模型生成内容进行内容安全审核。

如模型生成内容被判定存在违法、违规、敏感或风险内容，本平台有权不向用户返回该内容、部分返回、替换为安全提示，或采取其他必要措施。

### 7.3 人工复核

对于机器审核判断为存在风险、违法、敏感或需要进一步确认的内容，本平台可能交由人工进行必要复核。

**用户理解并同意，内容安全审核是本平台履行法律法规要求、保障平台安全、维护用户和公众合法权益的重要措施。**

## 九、您在跨境传输中的权利

### 9.1 知情权

### 9.2 查阅、复制权

您有权依法查阅、复制我们处理的您的个人信息。您可以通过本说明载明的联系方式向我们提出请求。

### 9.3 更正、补充权

如您发现我们处理的您的个人信息不准确或不完整，您有权要求我们更正或补充。

### 9.4 删除权

在法律法规规定的情形下，您有权要求我们删除您的个人信息。

但对于以下信息，我们可能无法立即删除，或需要在相应期限届满后删除或匿名化处理：

（1）依法必须保存的记录；  
（2）交易、账务、发票、税务记录；  
（3）安全审计、违规记录和风控记录；  
（4）投诉、申诉、争议处理所需记录；  
（5）监管、司法或行政机关要求保存的数据。

### 9.5 撤回同意

您有权撤回您对跨境传输所给予的同意。您可以通过本说明载明的联系方式向我们提交撤回同意请求。

**请您理解，跨境传输是本平台网页聊天、API 代理和第三方模型调用服务的必要环节。您撤回同意后，我们可能无法继续向您提供相关核心服务。**

撤回同意不影响撤回前基于您的同意已经进行的跨境传输和处理活动的效力。

### 9.6 限制或拒绝处理

在法律法规规定的情形下，您有权要求限制或拒绝我们处理您的个人信息。但如果相关处理是提供本平台核心服务所必需的，您限制或拒绝处理可能导致我们无法继续向您提供全部或部分服务。

### 9.7 向境外接收方行使权利

如您希望就境外接收方处理您的个人信息事项行使权利，您可以先通过本说明载明的联系方式联系我们。我们将在合理范围内协助您联系相关境外接收方或提供相关处理路径。

但请您理解，第三方模型服务商作为独立服务提供者，可能有其自身的权利行使流程、身份验证要求和响应期限。

## 十一、风险提示

### 11.1 境外法律环境差异
