# 创建 API 密钥

API Key 用于客户端和应用调用 Oproxy。不要在文档、截图、聊天消息或代码仓库中写入真实密钥。

## 创建前

1. 登录 [Oproxy 控制台](https://oproxy.world/dashboard)。
2. 在 **模型定价** 中确认目标模型与分组。
3. 在 **API 密钥** 页确认账户余额、现有 Key 和两个可用端点。

## 创建步骤

1. 打开 [API 密钥](https://oproxy.world/keys)，点击 **创建密钥**。
2. 填写名称，建议按用途命名，例如 `codex-laptop`、`claude-code`、`chat-client`。
3. 选择分组。常见分组包括：按量计费、OpenAI-按量计费、Claude、Gemini 和 DeepSeek；实际列表会随账户变化。
4. 按需设置自定义密钥、IP 限制、额度限制、速率限制和密钥有效期。
5. 检查无误后再点击 **创建**。

![创建 API 密钥弹窗](/images/oproxy-steps/create-key-dialog.png)

*图：名称、分组和各项限制都集中在创建弹窗内；图中未填写真实密钥。*

| 设置 | 用途 |
| --- | --- |
| 分组 | 限定可用模型与计费渠道 |
| 额度限制 | 限制该 Key 的最大消费；页面说明 `0` 为不限制 |
| IP 限制 | 只允许指定来源调用 |
| 速率限制 | 控制请求速度 |
| 有效期 | 到期后自动失效 |

## 列表操作

密钥列表支持搜索、分组和状态筛选、刷新、排序与分页。每个 Key 可执行：

- **复制**：复制密钥；只在受信任设备使用。
- **使用密钥**：打开客户端配置提示，可能显示完整 Key。
- **禁用**：立即停止调用，适合怀疑泄露时使用。
- **编辑**：修改名称或限制。
- **删除**：不可逆，确认没有应用仍依赖该 Key。

::: warning 安全建议
不同设备和应用使用不同 Key。生产 Key 设置额度、IP 和有效期；发现异常先禁用，再检查使用记录，最后决定是否删除和重新创建。
:::

## API 端点

- 默认：`https://api.oproxy.world`
- 国内优化：`https://open.oproxy.world`

![API 密钥页面展示的默认端点和国内优化端点](/images/oproxy-steps/api-endpoints.png)

*图：API 密钥页提供两个端点的复制和测速入口。*

页面提供复制和测速入口。具体是否追加 `/v1` 取决于客户端，参见 [API 端点与协议](/docs/tokenflux/endpoints.html)。
