# 邀请返利

邀请新用户注册，并将返利额度转入账户余额。

## 页面入口

登录 Oproxy 后，在左侧导航栏打开 [邀请返利](https://oproxy.world/affiliate)。

![未开通邀请权限时的邀请返利页面](/images/oproxy-steps/referral-access.png)

*图：未开通邀请码时的页面状态；开通后的入口和数据以账户内实时页面为准。*

## 邀请权限

### 暂未开通邀请权限

没有专属邀请码时，页面会提示普通用户暂无法邀请新用户注册。如需开通邀请权限，请联系微信客服。

[联系微信客服](https://work.weixin.qq.com/ca/cawcde03c0826cf9e7)

::: info 开通后的页面
获得邀请权限后，页面可能显示邀请码、邀请链接、返利统计、返利转余额和受邀用户明细。返利比例、额度和操作条件以账户内实时页面为准。
:::

## 校园大使计划入口

校园大使仅面向支持的学校教育邮箱开放。

申请前请阅读校园大使计划的奖励规则、审核要求和活动边界。

[查看校园大使计划](/docs/tokenflux/campus-ambassador.html)
