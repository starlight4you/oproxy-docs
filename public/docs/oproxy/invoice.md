# 订单、兑换与账务记录

## 我的订单

[我的订单](https://oproxy.world/orders) 支持按状态筛选、刷新和分页，列表包含订单 ID、订单编号、实付金额、支付方式、状态与创建时间。

常见状态包括已完成和已取消。订单页面用于核对支付结果；不要以浏览器返回页代替订单状态。

## 兑换码

[兑换](https://oproxy.world/redeem) 可增加余额、并发数或试用权限：

1. 输入兑换码，注意区分大小写。
2. 核对页面说明。
3. 点击 **兑换** 后才会提交。

![兑换码输入框和兑换按钮](/images/oproxy-steps/redeem-form.png)

*图：兑换操作区。截图未展示账户余额和历史活动。*

每个兑换码只能使用一次，成功后余额或并发数会即时更新。页面同时显示最近活动，包括兑换充值、管理员调整等。

::: warning 不要测试未知兑换码
无效或不属于你的兑换码不应反复提交。遇到问题请保留兑换来源和提示信息，并联系支持。
:::

## 发票与退款

需要开票或退款且控制台没有独立入口时：

1. 准备账号、订单号、支付时间和金额。
2. 通过工单、微信客服或 `support@oproxy.world` 联系平台。
3. 只通过官方渠道提交必要信息，不发送 API Key 或密码。

![新建工单弹窗](/images/oproxy-steps/ticket-dialog.png)

*图：新建工单时选择分类、填写标题和问题描述；不要在附件或正文中提交完整密钥。*

## 账务记录的保存

交易、账务、发票、税务、退款和争议记录可能因法律与审计要求保留，账号注销后也不一定立即删除。详情以最新隐私政策和用户协议为准。
