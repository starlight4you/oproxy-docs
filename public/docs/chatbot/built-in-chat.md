是否可以创建会话、智能体或临时访问密钥，以当前控制台显示为准。功能维护期间，请等待公告更新，不要反复创建 API Key。

## 功能入口

登录 Oproxy 控制台，在左侧导航栏点击 [聊天/智能体应用](https://oproxy.world/app-centre)。

## 后续将补充

- 打开内置聊天应用；
- 创建会话并选择模型；
- 创建、续期和停用临时访问密钥；
- 创建与管理智能体；
- 管理历史会话、附件和工具权限；
- 常见错误与维护状态处理。

## 使用前注意

- 为聊天/智能体功能使用单独的 API Key，并设置额度和有效期。
- 不要在聊天内容、截图或工单中粘贴完整 API Key。
- 处理敏感内容前，阅读隐私政策、跨境传输说明和内容安全规则。
- 页面无法打开时，先查看控制台公告和模型监控，再联系支持。
