# Orders, Redemption, and Billing Records

## Orders

The Orders page supports status filtering, refresh, and pagination. It lists order ID, order number, paid amount, payment method, status, and creation time. Use the recorded status—not a browser return page—to confirm payment.

## Redemption codes

Codes are case-sensitive and can add balance, concurrency, or trial access. Each code can be used once, and successful changes appear immediately. Do not repeatedly submit unknown codes.

## Invoices and refunds

If the console does not provide a standalone invoice or refund entry, contact support or submit a ticket with the necessary account, order, time, and amount information. Never send a password or full API key.
