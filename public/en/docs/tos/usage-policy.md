## 二、我们如何收集和使用您的个人信息

### 2.1 个人信息和敏感个人信息的定义

根据《中华人民共和国个人信息保护法》，个人信息是指以电子或者其他方式记录的与已识别或者可识别的自然人有关的各种信息，不包括匿名化处理后的信息。

敏感个人信息是指一旦泄露或者非法使用，容易导致自然人的人格尊严受到侵害或者人身、财产安全受到危害的个人信息，包括生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹等信息，以及不满十四周岁未成年人的个人信息。

**本平台不主动要求您在用户内容中提交敏感个人信息。除非服务所必需、法律法规要求或您已依法取得相关授权，否则请勿通过本平台输入、上传或传输他人的个人信息、敏感个人信息、商业秘密、保密信息或其他受保护信息。**

## 三、网页聊天数据的处理规则

### 3.1 网页聊天内容的保存

当您使用本平台网页聊天服务时，您输入的内容、会话上下文以及模型返回的内容可能会保存于您的账号中，以便您查看历史记录、继续会话和管理聊天内容。

网页聊天记录可能包括：

（1）您输入的提示词、问题、指令、文本或其他内容；  
（2）模型生成并返回的内容；  
（3）会话标题、会话时间、所调用模型、上下文信息；  
（4）与会话相关的必要技术信息。

### 3.2 用户删除网页聊天记录

您可以自行删除网页聊天记录。

**您删除网页聊天记录后，对于未触发内容安全风险、投诉争议或法律法规保存要求的普通聊天记录，我们将立即删除，不再保留该等普通聊天内容。**

但请您理解，如相关网页聊天内容已经触发内容安全审核、被认定为风险内容、违规内容，或涉及投诉、申诉、争议处理、监管配合、安全审计等情形，我们可能按照本政策和《Oproxy 用户服务协议》的约定继续保存相关内容和记录。

### 3.3 网页聊天内容的使用限制

我们不会将您的网页聊天内容用于本工作室自身模型训练，也不会出售您的网页聊天内容。

但您通过网页聊天调用第三方模型服务商时，相关内容可能会被传输至第三方模型服务商。第三方模型服务商可能依据其自身条款、隐私政策或数据处理规则处理相关数据。

## 四、API 服务数据的处理规则

### 4.1 API 请求和响应内容

当您使用 API 代理服务时，您通过 API 提交的请求内容、上下文、参数和第三方模型服务商返回的响应内容，会经由本平台进行必要的鉴权、计费、内容安全审核、转发和返回处理。

**对于未触发内容安全风险的正常 API 请求，本平台原则上不长期保存完整的用户输入内容和完整的模型输出内容。**

### 4.2 API 元数据日志

为完成计费、账单、故障排查、安全审计和风控需要，我们会保存必要的 API 请求/响应元数据日志 30 天，包括但不限于：

（1）用户 ID；  
（2）IP 地址；  
（3）请求时间；  
（4）调用模型；  
（5）token 数；  
（6）消耗金额；  
（7）请求状态、错误码或其他必要技术信息。

### 4.3 API 上下文内存缓存

为实现多轮对话、上下文处理、请求转发和结果返回，本平台可能在运行内存中临时保存 API 上下文内容。

**API 上下文内容的内存释放周期为 1800 秒。释放后，我们不再保留该等普通 API 上下文内容，但触发内容安全风险、违规记录、争议处理或法律法规保存要求的内容除外。**

### 4.4 API 密钥信息

当您创建和使用 API 密钥时，我们会处理以下信息：

（1）密钥标识符；  
（2）密钥创建时间、更新时间、删除时间；  
（3）密钥使用状态；  
（4）密钥关联账号；  
（5）密钥调用记录和异常使用记录。

我们建议您妥善保管 API 密钥，不要将密钥嵌入公开代码仓库、客户端前端页面或与第三方共享。如您发现密钥泄露，应立即删除或重置密钥。

## 五、内容安全审核与违规内容处理

### 5.1 审核目的

为履行法律法规要求、维护网络空间安全、保护用户和公众合法权益、防止本平台被用于违法违规用途，我们会对用户内容和模型生成内容进行内容安全审核。

### 5.2 审核对象

内容安全审核可能覆盖以下内容：

（1）您在网页聊天中输入的内容；  
（2）您通过 API 提交的请求内容；  
（3）您提交的上下文、参数、提示词或指令；  
（4）第三方模型服务商返回的模型生成内容；  
（5）本平台合理认为有必要审核的会话内容、请求内容和相关技术信息。

### 5.3 审核方式

本平台采用机器审核与人工复核相结合的方式进行内容安全审核。

机器审核方式包括但不限于：

（1）关键词规则；  
（2）自研审核模型；  
（3）分类模型；  
（4）风险评分；  
（5）上下文分析；  
（6）其他自动化安全检测技术。

**对于机器审核判断为存在风险、违法、敏感或需要进一步确认的内容，我们可能交由人工进行必要复核。**

### 5.4 自动化处理说明

我们可能使用自动化技术对内容安全风险、账号异常、接口滥用、计费异常、攻击行为等进行检测和判断。

**对于可能对用户权益产生重大影响的处置，例如账号封禁、长期限制服务等，我们会提供人工复核和申诉渠道。用户申诉成功后，我们将撤销或调整相应违规记录。**

### 5.5 风险内容和违规内容的保存

对于本平台审核认定存在风险的内容，我们可能保存相关内容及审核记录 180 天。

对于机器审核判断为违法、敏感或违规并被本平台拒绝的请求，我们可能将该次请求相关内容、上下文、模型返回内容、用户信息、请求时间、IP 地址、调用模型、处置结果等作为安全日志保存 180 天，并交由人工审核处理。

保存期限届满后，我们将删除或匿名化处理相关信息，但法律法规、监管要求、司法机关、行政机关或争议处理要求继续保存的除外。

### 5.6 违规处置与申诉

根据《Oproxy 用户服务协议》，用户在 180 天内累计触发 5 次经确认的违规记录的，本平台有权封禁账号。

对于严重违规行为，包括但不限于涉恐、法律法规禁止的政治类违法信息、儿童色情、攻击平台、批量滥用、侵犯个人信息权益、恶意绕过审核等，用户在 180 天内累计触发 3 次经确认的严重违规记录的，本平台有权封禁账号。

用户如认为审核结果、违规记录或封禁决定有误，可以通过以下方式申诉：

**邮箱：support@oproxy.world**  
或通过本平台页面公示的微信客服渠道提交申诉。

## 七、我们如何使用 Cookie 及同类技术

### 7.1 Cookie 的使用

为保障本平台网站正常运行、维持登录状态、提升使用体验和保障服务安全，我们可能在您的浏览器或终端设备中存储 Cookie。

我们使用的 Cookie 主要包括：

（1）必要类 Cookie：用于登录状态保持、会话管理、基础功能运行；  
（2）安全类 Cookie：用于防止 CSRF 攻击、识别异常登录、检测滥用行为；  
（3）偏好类 Cookie：用于保存必要的界面设置或使用偏好。

### 7.2 同类技术

除 Cookie 外，我们可能使用 LocalStorage、SessionStorage 等浏览器本地存储技术，用于会话管理、状态保持、安全验证和性能优化。

### 7.3 不用于广告追踪

**我们不会使用 Cookie 或同类技术进行跨站广告追踪、商业广告画像或与本平台服务无关的个性化广告推荐。**

### 7.4 用户选择

您可以通过浏览器设置管理、删除或禁用 Cookie。但如果您禁用必要类 Cookie，可能导致您无法登录或无法正常使用本平台部分功能。

## 八、我们如何存储和保护您的个人信息

### 8.1 存储地点

除为实现模型调用、API 代理、网页聊天和请求转发所必需的跨境传输外，我们在本平台账户、注册、计费、日志和风控系统中保存的个人信息，原则上存储于中华人民共和国境内服务器。

本平台中国大陆服务器主要使用中国大陆云服务资源，并已依法办理相关备案手续。

### 8.2 存储期限

我们仅在实现处理目的所必需的最短期限内保存您的个人信息，但法律法规另有要求或为处理争议、履行合同、安全审计、监管配合所必需的除外。

主要保存期限如下：

| 数据类型 | 保存期限 |
|---|---|
| 账号基本信息 | 账号存续期间保存；账号注销后一般保留 14 天 |
| 用户删除账户后的普通用户数据 | 一般保留 14 天后删除或匿名化 |
| 用户操作日志 | 保存 30 天 |
| API 请求/响应元数据日志 | 保存 30 天 |
| API 上下文内存缓存 | 1800 秒后释放 |
| 普通 API 请求完整输入和输出 | 未触发安全风险的，原则上不长期保存 |
| 网页聊天记录 | 用户未删除期间保存；用户删除后立即删除普通聊天记录 |
| 风险内容、违规内容、安全审核记录 | 保存 180 天 |
| 违法、敏感或被拒绝请求的安全日志 | 保存 180 天 |
| 充值、交易、退款、发票和税务记录 | 按法律法规、财务会计和税务要求保存 |
| 投诉、申诉、争议处理记录 | 在处理目的所需期限内保存 |
| 监管、司法或行政机关要求保存的数据 | 按相关要求保存 |

**账号注销或删除后，一般数据将按 14 天规则处理；但违规记录、安全日志、账务税务记录、争议处理记录、依法应保存记录不受该 14 天期限限制。**

### 8.3 安全保护措施

我们采取合理的技术和管理措施保护您的个人信息安全，包括但不限于：

（1）传输层加密，例如 HTTPS/TLS；  
（2）访问控制和身份认证；  
（3）最小权限管理；  
（4）安全审计和日志记录；  
（5）接口限流、风控和异常检测；  
（6）密钥安全管理；  
（7）服务器和网络安全防护；  
（8）工作人员数据安全和个人信息保护培训；  
（9）数据安全事件应急响应机制。

### 8.4 安全事件处理

### 9.1 跨境传输的必要性

### 9.2 跨境传输路径

本平台目前通常的数据传输路径为：

**中国大陆服务器 → 境外服务器 → 第三方模型服务商。**

第三方模型服务商可能位于中华人民共和国境外。

### 9.3 可能跨境传输的信息类型

为实现模型调用和请求转发，我们可能向境外传输以下信息：

（1）您输入的提示词、文本、指令或其他用户内容；  
（2）必要的上下文内容；  
（3）请求参数；  
（4）所调用模型信息；  
（5）第三方模型服务商返回的模型生成内容；  
（6）实现请求转发、错误排查、结果返回所必需的技术信息。

我们不会因跨境传输目的主动向境外传输您的手机号、教育邮箱、充值记录、发票信息等账户和财务信息，除非为实现特定服务、法律法规允许或您另行授权所必需。

### 9.4 第三方模型服务商的数据处理

您理解并同意，第三方模型服务商可能依据其自身服务条款、隐私政策、数据处理规则或用户设置，对接收到的用户内容和模型生成内容进行存储、分析、服务改进、模型训练或其他处理。

如您对数据不被第三方模型服务商用于训练、保留或分析有特殊要求，请在使用相关服务前联系本平台客服或销售，申请开启专门的数据保护通道或签署另行服务协议。

### 9.5 特殊数据保护需求

实验室、企业、研发团队或其他对保密、科研数据、商业秘密、个人信息、训练禁用、专属上游、数据隔离等有特殊要求的用户，应主动联系本平台销售或客服，并在使用相关服务前明确告知其特殊需求。
